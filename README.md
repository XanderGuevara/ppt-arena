# PPT Arena

Piedra, Papel o Tijera es una aplicación interactiva desarrollada con React y Vite. Permite jugar contra la CPU en una serie de hasta tres puntos y consultar el historial de rondas.

## Funcionalidades

- Personalizar el nombre del jugador.
- Elegir piedra, papel o tijera.
- Competir contra una selección aleatoria de la CPU.
- Llevar el marcador de victorias, derrotas y empates.
- Ganar la serie al alcanzar tres puntos.
- Consultar el historial de rondas y limpiar el registro.
- Reiniciar el marcador durante una partida.

## Tecnologías

- React
- React Router
- Vite
- Bootstrap
- JavaScript
- CSS

## Ejecución local

```bash
npm install
npm run dev
```

Para generar y revisar la versión de producción:

```bash
npm run lint
npm run build
npm run preview
```

## Rutas

- `/` — Arena de juego.
- `/historial` — Historial de rondas.
